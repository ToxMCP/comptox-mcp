# QA & Onboarding Checklists

This directory contains versioned checklists for SMEs, QA engineers, and new developers. Each checklist references the scripts, docs, and automation tasks required for MCP Phase 2 readiness reviews.

- `transport_smoke_checklist.md` – WebSocket transport + Agentic SDK validation.
- `predictive_guardrail_checklist.md` – Applicability-domain enforcement and audit bundle verification.
- `onboarding_checklist.md` – Developer onboarding, environment bootstrap, and CI verification.

Update the checklists when workflows change and capture stakeholder sign-off in release notes.
