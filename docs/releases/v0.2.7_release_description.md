# v0.2.7 Release Description

CompTox MCP v0.2.7 is a maintenance patch for the evidence federation server. It refreshes transport dependency protections and the scientific validation runtime while preserving the public tool catalog, published schemas, and scientific assets.

## Maintenance changes

- Require AnyIO 4.14.2 or newer and refresh the committed dependency lock to AnyIO 4.15.1.
- Refresh typing-extensions to 4.16.0 on supported Python versions where its package marker permits it.
- Run the scientific-invariants CI gate with Node.js 22.
- Populate `get_contract_manifest` response/portable schema inventories and example references from installed package data when the server runs outside a source checkout.
- Include the existing portable schemas and examples in wheel/source distributions, and check their inventory in the standalone-wheel CI gate.
- Align current package/release documentation, and correct the README Python badge to the supported 3.10 minimum.

## Validation

Release preparation verifies the current runtime/development lock against the advisory database, runs the existing public-surface contract and full offline test gates, and checks initialization, catalog discovery, and schema loading from an installed wheel outside a source checkout.

EPA-backed readiness, chemical data calls, and live cross-suite fixture refreshes require a CompTox API key and remain separate live release gates. Follow the [release artifact verification guide](release_artifact_verification.md) for signed artifacts after publication.
