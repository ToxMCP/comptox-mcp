# v0.2.4 Release Description

**Release date:** 2026-07-20

This patch release restores MCP tool discovery for clients that strictly validate paginated list responses.

## Interoperability fix

- `tools/list` and `resources/list` omit `nextCursor` when no additional page exists instead of serializing the optional string field as JSON `null`.
- HTTP and WebSocket transports now encode terminal and continued pagination consistently.
- String-valued continuation cursors remain available when another page exists.

## User impact

Claude Code 2.1.214 previously connected to the HTTP transport but rejected the tool catalog with `Invalid input: expected string, received null (at nextCursor)`. The corrected response is accepted and exposes the complete CompTox MCP tool catalog.

The repair does not require stateful HTTP sessions or an `Mcp-Session-Id` header. Authentication and CompTox API behavior are unchanged.

## Validation

- Full Python test suite: 243 passed.
- Formatting checks: Black passed for the modified Python files.
- End-to-end HTTP discovery: Claude Code 2.1.214 reports the server as connected and successfully discovers all tools.

## Scope

This release is intentionally limited to transport interoperability, pagination response correctness, regression coverage, and matching release metadata. The public tool catalog and domain contracts are unchanged.
