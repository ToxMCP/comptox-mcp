# v0.3.0 Release Description

**Unreleased migration candidate.** Stable MCP Python SDK 2.2.0 adds protocol 2026-07-28 HTTP and dual-generation stdio while preserving the existing HTTP/WebSocket contracts. No deployment or package publication is performed by this change.

All 85 tools, ten resources, scientific output schemas, handoffs, metadata and provenance remain. Experimental predictive/orchestrator tools remain outside the default catalog. Python 3.10 remains supported.

The [migration guide](../mcp_sdk2.md) documents metadata representation, modern routing headers, authority allowlists, body bounds and the installed real-client gate. A release requires separate approval after hosted checks pass.
