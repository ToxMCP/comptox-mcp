# v0.2.6 Release Description

CompTox MCP v0.2.6 is a packaging-only follow-up to v0.2.5. It preserves the chemical-result, authentication, metadata, and search-default fixes from v0.2.5 while making binary distributions self-contained.

## Fixed

- Include every MCP response-schema namespace in wheel installations.
- Resolve the installed schema bundle through Python's active installation data path when no source checkout is present.
- Start and serve `initialize`, `tools/list`, and authenticated BPA tool calls from a clean wheel-only environment.

## Why a follow-up release was needed

The v0.2.5 source checkout passed its full test suite and authenticated live gate, but final artifact verification found that its wheel relied on the repository's `docs/contracts/schemas` tree. The immutable v0.2.5 tag and attestations are retained; v0.2.6 is the corrected standalone distribution.
